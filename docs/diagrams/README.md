# Architecture diagrams

These diagrams are compact visual companions to the authoritative prose in `docs/` subject folders.
The `.dot` files are the editable sources; `.svg` is convenient for repository/browser viewing and `.pdf` for print/reference.

The diagrams distinguish ManatOS/company ownership from protoCRM/platform ownership and use **entity infrastructure** for the reusable metadata/CTX/storage framework. **SysBO** is reserved for system-owned business objects and is not a synonym for every future entity.
