# Purpose and Scope

The platform provides the CRM domain layer in which customer/organization relationships and applications can be modeled while sharing the common entity, metadata, security, context and UI runtime.

Implemented administration/domain foundations currently center on Principals, Users, Applications, Licenses and normalized contact information. The platform catalog additionally identifies broader CRM capability directions—customer views, opportunities, activities, communications, documents and analytics—which are design direction rather than a claim that all those modules are already complete.
