# protoCRM Design

protoCRM is the current CRM-oriented platform built on the reusable foundation. It is both functional product work and a concrete exercise of the platform contracts.

Current system/domain objects used by the platform include Principals and organization hierarchy, Users/identity, Applications, Licenses, email addresses, telephone numbers, postal addresses and their principal link entities. External authentication providers and system configuration support the surrounding system administration domain.
