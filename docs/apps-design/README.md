# Application and Platform Design

This area is for people designing business applications on the foundation rather than modifying the framework itself.

The design vocabulary is **Company → Platform → Application**, with canonical entities/relationships and metadata-driven UI composition underneath. A platform can contribute navigation, presentation and entity capabilities while reusing common runtime/security/storage mechanisms.

Read [Platform Model](Platform-Model.md), [Application Model](Application-Model.md), [Application Design Principles](Application-Design-Principles.md), and [Metadata-Driven Application Design](Metadata-Driven-Application-Design.md). The [protoCRM](protocrm/README.md) folder shows the current concrete platform.
