# Administration

Administration currently includes system/business-object management such as Users, Principals, Applications and external authentication/provider-related configuration according to the authenticated user's capabilities.

Use list filters/search to locate records, open an entry to edit, and Save/Save and Close to commit changes. Delete availability is record-policy dependent and can differ even between records of the same entity (for example, self-protection rules).

Related collections and hierarchy tabs expose domain relationships without requiring manual editing of foreign-key identifiers.
