# Navigation

Navigation is composed from system and platform contributions. Items may be dynamically visible according to current user/platform capabilities and required entity availability.

Breadcrumbs and nested entity interaction reflect logical UI ownership. Opening a record from a list creates a nested entry context; selectors/popups are children of the entry rather than unrelated pages.

If an expected administrative item is absent, first consider current role/platform access rather than treating menu visibility as the authorization rule itself.
