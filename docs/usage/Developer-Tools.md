# Developer Tools

When developer mode is enabled, the Developer Tools surface provides CTX Viewer and API Traffic inspection, with debugging CLI support.

Use CTX Viewer to inspect the current root context and nested UI levels, pin targeted paths, examine field/state values and follow reactive changes. Use API Traffic to correlate UI actions with HTTP activity. The tool window can detach while remaining attached to the same live page runtime.

Workspace layout/inspection preferences can persist; live CTX values and traffic do not become persisted application data.
