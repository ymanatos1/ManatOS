# Getting Started

After the UI and API are running, open the UI host in a browser and authenticate with an available local or external-provider flow. The shell exposes company/platform navigation and administration options according to safe capability facts returned for the current user.

Entity administration uses a consistent list → entry interaction. Lists provide filtering/search/paging and row actions; entries use metadata-defined tabs and fields. Nested selectors/popup editors can be opened without leaving the owning entry.

Developer mode can expose Developer Tools for CTX/API inspection; these tools are diagnostic and do not change normal authorization.
