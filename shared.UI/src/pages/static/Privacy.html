3. Why we process data and our legal bases

Depending on the activity, processing is based on:

  • Contractual necessity (GDPR Article 6(1)(b)): providing accounts, access to requested services and related account functionality.
  • Legitimate interests (Article 6(1)(f)): protecting services against unauthorized access, investigating technical problems, preventing abuse and maintaining operational security, subject to applicable safeguards.
  • Legal obligations (Article 6(1)(c)): complying with applicable accounting, regulatory and other statutory requirements.
  • Consent (Article 6(1)(a)): only where we specifically request consent for an optional activity for which consent is the appropriate legal basis.

Additional legal bases may apply to business information processed on behalf of an organization. Those purposes and responsibilities must be communicated by the relevant controller.

4. Registration, passwords and account security

We use account information to verify identities, manage access permissions and operate authentication sessions. Passwords are protected using password-hashing mechanisms rather than stored as readable passwords.

Email verification, password recovery and external identity-provider functions, when enabled, may require short-lived security credentials and the processing of relevant email addresses or provider identifiers.

The publicly accessible API and the UI authentication server apply security controls such as rate limiting. These controls process network and authentication-attempt information to discourage password guessing, account abuse and automated attacks.

The API may retain security-related records in its existing datastore where persistence is needed. UI servers do not require a separate database for browser-session management; their temporary session state can be maintained in server memory.

5. Cookies and browser storage

ManatOS uses essential authentication and security storage to provide the account functionality requested by users.

Name or category Purpose Duration
manatos_ng1_auth First-party session cookie used for browser authentication and CSRF-protected operations. It contains an opaque identifier, not a password or API access token. Up to 30 minutes, or less when the underlying API session expires. It may also be cleared on Sign Out.
manatos.ui.preferences.v2 Browser local storage for interface preferences such as theme, language and font scaling. Persists in the browser until cleared, replaced or removed by the user or application.
UI state storage Browser local or session storage used to restore navigation, window, tab and interface state. Depends on the specific state record and browser storage mechanism.

In production, the authentication cookie is configured as HttpOnly, Secure and SameSite=Lax. The cookie is restricted to the authentication endpoint path. API access tokens are retained on the server rather than deliberately stored in this cookie or in browser local storage.

Strictly necessary authentication and security cookies do not require prior consent under applicable Greek electronic communications rules. Optional storage requested by a user for interface preferences is treated separately according to its function and the applicable rules.

The current authentication implementation does not require advertising or behavioral-tracking cookies. If we introduce non-essential analytics, advertising or similar technologies, we will provide the required information and consent controls before activating them.

You can manage or delete cookies and local storage through your browser settings. Removing essential authentication data may require you to sign in again or may prevent authenticated functions from working.

  • Rate-limiting counters are temporary and expire under the applicable security windows.
  • Account, business and security records may require longer retention where justified by an active service relationship, investigation or legal obligation.

Before publication: the operator must publish its verified retention periods or objective retention criteria for account, audit, backup and security records.
